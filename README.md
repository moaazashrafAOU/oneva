# ONEVA — موقع البروفايل والمنتجات

المشروع الكامل موجود في مجلد `oneva website`. الصفحة الرئيسية `/` هي بروفايل الشركة، والكتالوج في `/catalog/`. روابط الفئات تحمل الفئة المختارة إلى صفحة الكتالوج. اللغة والسلة محفوظتان على الجهاز عند التنقل بين الصفحتين.

تتضمن صور البروفايل `supply-warehouse.webp` و`quality-preparation.webp` مشاهد توضيحية مولدة للتوريد وتجهيز الطلبات، وليست توثيقاً لمقر أو موظفي الشركة.

موقع عربي متجاوب، يُصدّر إلى ملفات HTML/CSS/JS ثابتة، بلا قاعدة بيانات أو خادم تطبيقات. يتضمن ٤١ منتجاً، ٤ فئات، بحثاً عربياً وسلة محلية وطلب عرض سعر عبر واتساب.

يدعم العربية والإنجليزية عبر زر اللغة في رأس الصفحة. تتغير اتجاهات الصفحة والنصوص والمنتجات ورسالة واتساب حسب اللغة المختارة، ويُحفظ الاختيار محلياً. الترجمة في `app/i18n.ts`، والبحث يقبل أسماء الأصناف باللغتين مع الاحتفاظ بمحتويات السلة عند التبديل.

## تغيير رقم واتساب

عدّل `public/site-config.json` وضع الرقم الدولي بأرقام إنجليزية، مثلاً `201012345678` (مثال فقط). القيمة الحالية فارغة عمداً حتى لا تُرسل الطلبات إلى شخص آخر. عند رفع النسخة الجاهزة، يمكن تعديل `site-config.json` داخل ملفات النشر مباشرةً دون إعادة بناء.

## التشغيل والتصدير

```sh
npm install
npm run dev
npm run build
```

ارفع **محتويات** `dist/client/` إلى جذر أي استضافة ملفات ثابتة. لا تحتاج PHP أو Node على الاستضافة. استخدم HTTP محلياً للمعاينة، وليس فتح HTML ببروتوكول file://.

## تعديل المنتجات

البيانات في `app/products.ts`: الاسم، الفئة، المنشأ، وحدة الطلب والتعبئة. الأصناف الغذائية بالكيلوجرام؛ كراتين التعبئة بالكرتونة؛ البولات والجوانتي بالوحدة. يمكن تغيير الوحدات حسب طريقة البيع الفعلية.

الأسعار غير محددة ولم يتم اختلاقها. رسالة واتساب تتضمن اسم الصنف، مواصفات العبوة، الكمية، الوحدة، وبيانات العميل الاختيارية. الضغط يفتح واتساب ولا يُرسل الرسالة تلقائياً؛ العميل يراجعها ويرسلها هناك.

## الصور والهوية

اللوجو والألوان والمحتوى التعريفي مستمدة من ملفات ONEVA المرفقة. الصور مولّدة توضيحياً، وليست صور عبوات تجارية موثّقة. شبكة الصور `public/products-atlas.webp` بها ٣٦ صورة، وكل خلية بنسبة ٤:٣. تستخدم المنتجات المتشابهة الصورة نفسها. عند توفر صور المنتجات الأصلية يُفضّل إحلالها.

## التحقق

`node scripts/check-order.cjs` يتحقق من اكتمال الكتالوج، تنظيف السلة، البحث العربي ومحتوى وروابط واتساب. لم يتم إرسال رسائل فعلية. لا يتطلب الموقع دعم WebMCP؛ الأداة الاختيارية تجهيز للسلة فقط، ولم يتوفر سياق WebMCP للتحقق منها.

قبل استقبال الطلبات فعلياً: أضف رقم الشركة الصحيح، وراجع الوحدات والمواصفات. بيانات السلة محفوظة على جهاز الزائر فقط، وبيانات العميل تنتقل عبر واتساب عند اختياره الإرسال.
